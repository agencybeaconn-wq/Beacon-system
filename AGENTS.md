# NODE System — instruções para agentes

Antes de qualquer tarefa:

1. Leia `../docs/AI-COLLABORATION.md`.
2. Para o módulo mobile, leia `../docs/APP-MOBILE-HANDOFF.md`.
3. Leia `CLAUDE.md` para regras específicas e catálogo de skills.
4. Consulte o JEB a partir de `C:\Users\Cliente\Obsidian-juvito\MOC.md`.
5. Se houver correspondência, leia integralmente `.claude/skills/<nome>/SKILL.md`; adapte explicitamente somente ferramentas incompatíveis.

Após mudança material, atualize o handoff e `../docs/AI-SESSION-LOG.md`. Nunca registre segredos.
